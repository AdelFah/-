# AI-планировщик задач — Telegram Bot

Telegram-бот с AI на базе Claude для планирования задач и управления расписанием.

## Возможности
- Создание задач через естественный язык
- Планирование дня и недели
- Напоминания и уведомления о дедлайнах
- AI-анализ расписания и советы по продуктивности
- Категории: учёба, работа, питание, спорт, отдых, личные, бытовые

## Установка

```bash
pip install -r requirements.txt
```

Создай файл `.env`:
```
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ANTHROPIC_API_KEY=твой_ключ_anthropic
```

## Запуск

```bash
python main.py
```

## Примеры команд боту
- «Добавь задачу помыть посуду сегодня в 18:00»
- «Напомни о тренировке завтра в 7:00 за 30 минут»
- «Покажи задачи на неделю»
- «Выполни задачу #3»
- «Проанализируй моё расписание»
